# Landing Page

A landing page built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum. The goal of this project was to recreate a provided webpage design using HTML and CSS, with an emphasis on practicing Flexbox.

**[View Live Demo](https://danfeng-danny-wang.github.io/landing-page/)**

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Features

- Header with navigation links
- Hero section with a headline, image, and sign-up button
- Information section with four illustration placeholders
- Testimonial section
- Call-to-action section
- Footer

## What I Learned

Through this project, I practiced:

- Building a webpage with semantic HTML elements
- Using Flexbox to arrange and align elements
- Working with nested flex containers
- Managing spacing with margins, padding, and gaps
- Understanding the CSS box model and `box-sizing`
- Creating centered content containers with `max-width` and `margin: auto`
- Organizing CSS for readability and maintainability
- Using Git and GitHub to track changes and deploy a website with GitHub Pages
